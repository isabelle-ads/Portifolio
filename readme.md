# 💻 Portfólio - Isabelle Fernandes

Este é o meu portfólio pessoal, aqui apresento meus projetos, habilidades e trajetória acadêmica na área de tecnologia.

## 🚀 Tecnologias Utilizadas

* **HTML5:** Estrutura semântica do projeto.
* **CSS3:** Estilização com variáveis, Flexbox, Grid e animações personalizadas.
* **JavaScript:** Lógica para o efeito de "máquina de escrever" (typewriter) e controle de interações.
* **AOS (Animate On Scroll):** Biblioteca para animações de surgimento ao rolar a página.
* **Font Awesome:** Ícones modernos para navegação e redes sociais.

## ✨ Funcionalidades

* **Efeito Typewriter:** Texto dinâmico na home apresentando minhas funções (Estudante, Full Stack, Entusiasta de IA).
* **Glassmorphism:** Interface baseada em transparências e desfoque de fundo (backdrop-filter).
* **Animações Smooth:** Elementos flutuantes e transições suaves ao passar o mouse nos cards.
* **Design Responsivo:** Adaptado para diferentes tamanhos de tela.
* **Navegação Fluida:** Links internos com scroll suave para as seções Sobre, Projetos e Contato.
